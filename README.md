# Waymaker

A small physics puzzle game built by Green Eye Creative. Place blocks, launch
the ball, and guide it to the star.

## Levels
- **Level 1** — Normal + Power bounce blocks
- **Level 2** — Adds Splitter blocks + intermittent spinning hazards
- **Level 3** — Adds Speed boost blocks + more spinning hazards

## Running it
This is a single static `index.html` — no build step, no server required.
Open it directly in a browser, or deploy it as a static site (e.g. a Render
Static Site or GitHub Pages) pointed at this repo's root.
